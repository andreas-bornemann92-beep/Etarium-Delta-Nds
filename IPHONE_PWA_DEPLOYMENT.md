# ETARIUM – iPhone PWA Teststand

Dieses öffentliche Repository ist ausschließlich für die **iPhone-Hochformat-Testdemo** vorgesehen. Es ist keine Kanonfreigabe.

## Veröffentlichung
Der Workflow `.github/workflows/pages.yml` veröffentlicht nur, wenn die komplette PWA inklusive acht Bildschirmen und Icons im Repository vorhanden ist. Damit wird keine unvollständige oder irreführende Demo live geschaltet.

GitHub: Settings → Pages → Build and deployment → Source: **GitHub Actions**.

**Noch nicht veröffentlicht:** Die acht Bilddateien liegen derzeit nur im ETARIUM-Arbeitsstand. Sie müssen vor dem Deployment sicher übertragen werden. Keine Originalbilder oder privaten Projektdaten ungeprüft veröffentlichen.

Bei erfolgreichem Deployment: https://andreas-bornemann92-beep.github.io/Etarium-Delta-Nds/

Auf iPhone: Safari → Teilen → Zum Home-Bildschirm.
